
# **Fingerprint Feature Extraction and Conversion Workflow**

This document provides a step-by-step guide for running the Python scripts to preprocess fingerprint images, extract features, and convert them into formats compatible with the Circom framework.

---

## **1. Preprocess Fingerprint Images**

The first step involves preprocessing the fingerprint images and converting them into a `.pkl` file format.

### Command:
```bash
python preprocess.py 101_1.tif 101_2.tif
```

- **Input**: Two `.tif` files, `101_1.tif` and `101_2.tif`, which represent the fingerprint images.
- **Output**: This command will generate `.pkl` files that contain preprocessed features of the fingerprint images.
  
The `.pkl` files store the extracted features and are used as inputs for the next step.

---

## **2. Extract Features and Convert to JSON**

After generating the `.pkl` files, use the `pre.py` script to extract additional features and convert them into a format that is compatible with Circom.

### Command:
```bash
python pre.py pkl1 pkl2
```

- **Input**: The previously generated `.pkl` files (`pkl1`, `pkl2`).
- **Output**: This command will process the `.pkl` files and convert them into a JSON format suitable for Circom.

The `.json` file produced will be used as input for the ZK-SNARK proof generation in the Circom workflow.

---

## **Note on Compatibility**

- The `.pkl` files are generated by `preprocess.py` to store the extracted features from the input images. However, these files are **not directly compatible with Circom**. Therefore, they must be converted into the JSON format by the `pre.py` script.
  
- The JSON format produced in the second step contains the data in a structure suitable for ZK-SNARK circuits. This data can then be used in the later stages of the proof generation process with Circom.

---

## **Files Overview**

- **`preprocess.py`**: A Python script that preprocesses fingerprint images and stores the features in `.pkl` files.
- **`pre.py`**: A Python script that extracts features from the `.pkl` files and converts them into a compatible `.json` format for Circom.

---

By following these steps, you can ensure the extracted fingerprint features are processed and formatted correctly for the subsequent ZK-SNARK circuit generation.
